# Aaspass Frontend

The Aaspass frontend gives users a clean way to sign in, discover nearby events, search, create events, upload images, and view event details.

## Main Screens

- Sign in
- Nearby event feed
- Event search
- Create event
- Event details

## Notes

Location access is used to personalize the home feed. Images can be previewed before upload and are shown again on event cards and detail pages.
