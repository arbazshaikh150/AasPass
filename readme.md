# Aaspass

Aaspass helps people discover events happening around them and create their own local gatherings.

## What You Can Do

- Sign in securely with Google.
- See nearby events based on your current location.
- Search for events by name, topic, or tags.
- Create free or paid events.
- Add event images, descriptions, tags, seats, and location.
- Open an event to view its details and images.

## Experience

The app is designed around a simple flow:

1. Sign in.
2. Allow location access.
3. Browse nearby events.
4. Search when you know what you want.
5. Create an event when you want people nearby to find it.

## Notes

Aaspass is built for local discovery, so location access is important for the home feed. Event images are uploaded before an event is published, then shown in the feed and detail pages.
